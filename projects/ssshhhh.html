Ssshhhh

SSH Key Management for macOS, simplified.

Generate, organise, and deploy SSH keys without touching the terminal. Built for developers who want a clean, native macOS experience for managing their keys.

Features

Key Generation

Create ED25519 and RSA keys with sensible defaults. No need to remember command-line flags.

Key Organisation

Tag, group, and search your keys. Always know which key goes where — no more guessing in ~/.ssh.

Agent Management

Add and remove keys from ssh-agent with a click. See what's loaded at a glance.

Native macOS

Built with Swift and AppKit. Feels right at home on your Mac — fast, lightweight, and native.
